# Лендинг «ИИ в работе линейного менеджера» — тестовая сборка

Подготовлено 18.11.2026 на основе утверждённого файла `AI_lineynyi_menedzher_prototip (16).html`.

## Состав

- `index.html` — страница;
- `css/style.css` — исходные стили, вынесенные без изменения правил;
- `js/main.js` — исходный расчёт высоты блоков и блокировка отправки формы;
- `images/` — 10 исходных фотографий WebP, извлечённых без перекодирования;
- `.nojekyll` — маркер статического комплекта;
- `README.md` — описание тестовой версии.

13 SVG-иконок сохранены внутри HTML. Отдельных используемых PNG и SVG-файлов в исходнике нет. Внешние библиотеки, шрифтовые сервисы, аналитика и серверная часть не используются. Шрифт выбирается из исходного системного стека; точное начертание может зависеть от операционной системы.

## Просмотр и тестовое размещение

Откройте `index.html` в браузере. Сохраняйте взаимное расположение файлов и папок.

Для GitHub Pages загрузите содержимое комплекта в корень отдельного публичного тестового репозитория. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. Пути к ресурсам относительные и пригодны для размещения в подпапке репозитория.

## Форма

Это статический предпросмотр: поля, флажки и кнопка отключены, обработчик submit блокирует стандартную отправку. Сетевой обработчик не задан. Данные не вводятся и не отправляются. Исходное предупреждение о неподключённой отправке сохранено. Шаблоны успешного ответа и ошибок в HTML не отображаются и не вызываются кодом.

Точка последующей интеграции — `form.request-form.feedback-form` в `index.html` и отдельный будущий обработчик отправки. До интеграции не снимайте `disabled` и не удаляйте блокировку submit. Серверный обработчик, CRM, почта, антиспам и юридические тексты в комплект не входят. Контактных телефона и почты в утверждённом прототипе нет; самостоятельно они не добавлялись.

## Индексирование и статус

Установлен `<meta name="robots" content="noindex, nofollow">`. Карта сайта и аналитика не подключены. Запрет обхода в robots.txt не добавлялся, чтобы робот мог прочитать noindex. Публикация остаётся публичной.

Это тестовый комплект, не окончательный релиз. После проверки опубликованного сайта будет отдельно подготовлен `landing-release.zip` с полной документацией для постоянного размещения. Перед постоянным запуском необходимо проверить индексирование, HTTPS, отображение на устройствах и подключение формы.

Проверены комплектность ресурсов, декодирование фотографий, относительные пути, якоря, уникальность ID, ссылки ARIA, метки формы, синтаксис JavaScript и неизменность текста страницы.

Браузерный визуальный прогон в среде подготовки недоступен. Горизонтальная прокрутка, наложения, реальная работа интерактива и скорость загрузки на устройствах пока не подтверждены. Их необходимо проверить после тестового размещения. Подробности — в отдельном техническом отчёте.
